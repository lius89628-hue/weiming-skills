# 小鲸娘桌面宠物（DSH 插件）

原创二次元桌宠「小鲸娘」，给 DeepSeek Harness（DSH）用。当前版本：2.0.0（63 段透明动画 + 63 张 PNG 备用图）。

- 单击说一句暖心话；1 秒内连点 3 下会喊疼；可以随便拖动，位置会记住
- 右键换配色（冰蓝 / 樱粉 / 薄荷绿 / 暗夜紫 / 柠檬黄）和造型（水手服 / 卫衣 / 睡衣 / 打工装 / 小斗篷），选完会记住
- 跟着 DSH 状态变表情：思考时眯眼笑、完成时庆祝、拒绝授权时委屈、任务超 5 分钟心疼钱、半夜 12 点后犯困
- 不联网、不读你的其他文件；素材都在插件自己的 `assets` 文件夹里

## 小白安装（复制下面整段发给 DSH，先切到「创造模式」）

```
帮我安装「小鲸娘桌面宠物」插件：
1. 下载 https://github.com/lius89628-hue/weiming-skills/archive/refs/heads/main.zip ，解压后只保留里面的 xiaojingniang-pet 文件夹，放进当前工作区。
2. 把这个文件夹安装成 DSH 插件并启用。弹出授权时，先告诉我要装的是什么，我确认后再继续。
3. 装好后告诉我怎么换配色、换造型，以及怎么关掉它。
```

## 下载太慢？

国内直连 GitHub 有时较慢。可以多试几次，或者先在评论区告诉我，我会补一个国内下载地址。

## 管理

- 关掉 / 打开：DSH 左侧「插件」→ 已安装插件 →「小鲸娘桌面宠物 2.0」开关
- 右键小鲸娘：换配色、换造型、藏起来、退出

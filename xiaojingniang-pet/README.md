# 小鲸娘桌面宠物（DSH 插件）

原创二次元桌宠「小鲸娘」，给 DeepSeek Harness（DSH）用。当前版本：3.0.2（新增本地大脑聊天；63 段透明动画 + 63 张 PNG 备用图）。

## 3.0 新功能：本地大脑

- 双击小鲸娘弹出输入框，回车发送；回答在她头顶的气泡里边生成边显示，输入框保留，可以接着聊
- 右键菜单也有「和她聊天」；按 Esc、点 × 或点别处关闭输入框
- 用本机 Ollama 模型回答（模型名 `xjn-brain`，CPU 运行），只连 127.0.0.1，聊天内容不出电脑
- 人设：简短、可爱、偶尔吐槽，每句不超过 40 字；记住最近 10 轮对话，刷新 DSH 页面就清空
- 等回答时眯眼思考，答完开心庆祝；你难过或骂她时委屈含泪；聊天表情优先于深夜犯困
- Ollama 没开时不报错，气泡只说「我的大脑还没睡醒～」

## 原有功能

- 单击说一句暖心话；1 秒内连点 3 下会喊疼；可以随便拖动，位置会记住
- 右键换配色（冰蓝 / 樱粉 / 薄荷绿 / 暗夜紫 / 柠檬黄）和造型（水手服 / 卫衣 / 睡衣 / 打工装 / 小斗篷），选完会记住
- 跟着 DSH 状态变表情：思考时眯眼笑、完成时庆祝、拒绝授权时委屈、任务超 5 分钟心疼钱、半夜 12 点后犯困

## 小白安装（复制下面整段发给 DSH，先切到「创造模式」）

```
帮我安装「小鲸娘桌面宠物 3.0」插件：
1. 下载 https://github.com/lius89628-hue/weiming-skills/archive/refs/heads/main.zip ，解压后只保留里面的 xiaojingniang-pet 文件夹，放进当前工作区。
2. 检查本机有没有 Ollama（http://127.0.0.1:11434）。没有的话告诉我去 ollama.com 下载安装；装好后运行 ollama pull qwen3:8b，再运行 ollama cp qwen3:8b xjn-brain。
3. 把 xiaojingniang-pet 文件夹安装成 DSH 插件并启用。弹出授权时，先告诉我要装的是什么，我确认后再继续。
4. 装好后告诉我怎么和她聊天、怎么换配色换造型，以及怎么关掉它。
```

模型大约 5GB；没有独立显卡也能跑（CPU 每秒约 9 个 token）。不装 Ollama 也能用其他功能，只是聊天时她会说「我的大脑还没睡醒～」。

## 管理

- 关掉 / 打开：DSH 左侧「插件」→ 已安装插件 →「小鲸娘桌面宠物 3.0」开关
- 右键小鲸娘：和她聊天、换配色、换造型、藏起来、退出

      第一次用，照着做

      以「一句话做个桌面宠物」为例，用 DeepSeek Harness（下面简称 DSH）。

      1. 装好 DSH，登录

        官网下载桌面版。创造模式会消耗 DeepSeek 余额，开始前看一眼余额够不够。

      2. 新建会话，切到 创造模式

        输入框上方能切换模式。标准模式是平时干活用的；创造模式允许 DSH 给自己写插件、加功能。

      3. 权限选 工作区内修改

        在输入框左下角。它在工作区里可以自己改文件，超出范围会停下来问你。新手用这一档最稳。

      4. 粘贴那段话，发送

        它会自己研究、写代码、安装，大概十几分钟。中途弹出「等待审批」不用慌，照右边的办法判断。

      弹出「等待审批」时

      等待审批

      安装插件「小鲸鱼桌面宠物」到 DeepSeek Harness。安装后会一直保留，代码会在工作区之外运行。

      拒绝允许一次
      • 先读清楚它要做什么、动哪个文件夹。
      • 是你让它做的事，比如这次装插件，点「允许一次」。
      • 看不懂，或者跟任务无关，点「拒绝」，它会换个办法或者来问你。
      • 别图省事开「完全权限」。手动确认这一步，就是你的安全阀。

      常见问题

      技能包（skill）到底是什么？

      一个文件夹，里面是一份写给 AI 的「岗位说明书」（SKILL.md），有时还带几个小脚本。AI 读了它，就知道这类活该怎么干、哪些坑要避开。写一次，以后一直能用。第一期视频专门讲这个：什么是 Skill，7 分钟讲透。

      提示词和技能包有什么区别？

      提示词是一段话，复制粘贴就能用，适合一次性的事，比如做个宠物插件。技能包是一个文件夹，装好之后 AI 每次遇到这类活都会照着做。

      插件和技能包有什么区别？

      技能包是给 AI 看的说明书，教它怎么把某类活干好；插件是给 DSH 装的新功能，比如多一个面板、能画图表。技能包放进文件夹就能用，插件要安装，装的时候 DSH 会弹窗问你。

      我在国内，用哪个工具？

      推荐 DeepSeek Harness（DSH），国内直接能用，DeepSeek 价格也便宜。OpenCode、Cline 这类工具接上国内模型也一样能用。

      要会写代码吗？

      不用。会打字、会复制粘贴就行。每一条都写了一步一步的用法。

      安全吗？会不会动我的账号？

      所有内容都能在 GitHub 上直接看。这里的提示词和技能包不索要密码、不付费、不改系统安全设置；整理文件的那几条都要求它只移动不删除。从别处下载的技能包，安装前也建议先打开看看。

      收费吗？能商用吗？

      全部免费，MIT 许可，随便用、随便改，商用也可以。

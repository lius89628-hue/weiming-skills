常见问题

skill 到底是什么？

一个文件夹，里面是一份写给 AI 的“岗位说明书”（SKILL.md），有时还带几个小脚本。AI 读了它，就知道这类活该怎么干、哪些坑要避开、什么事绝对不能做。

用不了 Claude 怎么办？

skill 装在 Agent 工具里，不挑模型。在 Cline、OpenCode 这类工具里接上 DeepSeek、Kimi、通义等国内模型，一样能用。

安全吗？会不会动我的账号？

每个 skill 的代码都能直接在 GitHub 上读。规则里写明不索要密码、不付费、不改安全设置；需要账号信息的地方都只存在你自己电脑上。

收费吗？能商用吗？

全部免费，MIT 许可，随便用、随便改，商用也可以。

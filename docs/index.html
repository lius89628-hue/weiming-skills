Onboarding

上岗三步

以 Claude Code 为例，其他工具把文件夹放进它们各自的 skills 目录即可。

01

下载解压

在工单上点“下载”，得到一个 zip，解压出一个以 skill 名命名的文件夹。

02

放进 skills 目录

把文件夹移进去就行，不用安装任何依赖：

mkdir -p ~/.claude/skills && mv ~/Downloads/drama-storyboard ~/.claude/skills/

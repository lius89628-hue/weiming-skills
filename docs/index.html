怎么安装

三步用起来

选你在用的工具。不知道选哪个？国内用户选 DeepSeek Harness。

1

下载并解压

在技能包详情里点「下载」，解压后得到一个文件夹，比如 my-skill。

2

放进 skills 文件夹

把整个文件夹放到下面这个位置（没有就新建）：

C:\Users\你的用户名\.agents\skills\

Mac：~/.agents/skills/

3

重启 DSH，直接开口

重启后像跟同事说话一样提要求，DSH 会自己用上对应的技能包。

做到一半弹出「等待审批」不用慌：先看它要做什么、动哪个文件夹，是你让它做的事就点「允许一次」。详见 EP02。

下载 ZIP

在技能包详情里点「下载」，不用解压，直接留着 ZIP 文件。

2

上传到 Claude

打开 Claude 设置，先打开「代码执行和文件创建」，再到「技能」页面点「＋」→ 上传技能，选这个 ZIP。

3

打开开关

在技能列表里打开它的开关，回到对话直接提要求。菜单名称以实际界面为准。

常见问题

新手最常问的

技能包（skill）到底是什么？

一个文件夹，里面是一份写给 AI 的「岗位说明书」（SKILL.md），有时还带几个小脚本。AI 读了它，就知道这类活该怎么干、哪些坑要避开。写一次，以后一直能用。

我在国内，用哪个工具？

推荐 DeepSeek Harness（DSH），国内直接能用，DeepSeek 价格也便宜。技能包是开放格式，OpenCode、Cline 这类工具接上国内模型也一样能用。

要会写代码吗？

不用。下载、放进文件夹、重启，然后用中文说你要做什么就行。每个技能包都有对应的视频教程。

安全吗？会不会动我的账号？

每个技能包的内容都能在 GitHub 上直接看。规则里写明不索要密码、不付费、不改安全设置。从别处下载的技能包，安装前也建议先打开看看。

收费吗？能商用吗？

全部免费，MIT 许可，随便用、随便改，商用也可以。

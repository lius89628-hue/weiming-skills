# AI 短剧剧本与分镜（drama-storyboard）

目标：产出**能直接喂给 AI 出图、出视频、配音**的剧本，而不是给人看的文学剧本。每一个镜头都要让下游模型“只看这一条就能画对、配对”。

输出两类文件，格式见 `references/schema.md`：

- `bible.json`：整部剧的“设定圣经”——画风、反向词、角色、场景、音色、季大纲。整季只写一次，后面每集都引用它。
- `ep01.json`、`ep02.json`……：每集的分镜表。

写完必须跑一遍检查：`python3 scripts/check.py bible.json ep01.json`，有 ERROR 就改到没有为止。

## 第一步：问清三件事（问不到就自己定，并写进 bible 的 notes）

1. **题材和调性**：仙侠轻喜剧、都市逆袭、古风美食……一句话。
2. **画面**：竖屏 9:16（抖音/视频号）还是横屏 16:9（B站）；写实还是动画。
3. **单集时长**：默认 2 分钟左右，约 25–35 个镜头。

## 第二步：写 bible.json

- **style**：一段英文画风描述，所有镜头共用。写实剧用 “cinematic photorealistic film still … shallow depth of field, subtle film grain” 这类。**不要写颜色倾向词**（如 deep reds、teal and orange），会把所有人的衣服都染色。
- **negative**：反向词，至少包含 text、watermark、logo、extra fingers、deformed hands、modern clothing（古装剧）。
- **characters**：每个角色一个 id（拼音小写），`prompt` 用英文写**年龄、脸、发型、服装款式和颜色、标志性小物件**。服装颜色必须写死，后面每一集都不改。动物/神兽也算角色。
- **scenes**：每个场景一个 id，英文写清时间（清晨/黄昏/夜）、光线、标志物。画面里不要出现文字：加 “no text, plain banners”。
- **night_scenes**：哪些场景是夜戏，列出来。夜戏要单独的光线描述，否则全局画风里的 “bright light” 会把夜戏拉成白天。
- **voices**（可选）：每个角色一个音色名和语速，按你用的配音服务填。
- **outline**：季大纲，一行一集或一段集数。

## 第三步：写每一集分镜

每个镜头一条，字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | s01、s02……按顺序 |
| dur | 是 | 秒，2–6 |
| type | 是 | `insert` 空镜/环境，`action` 无台词动作，`talk` 有台词 |
| scene | 是 | bible 里的场景 id |
| chars | 是 | 本镜头出现的角色 id 列表，空镜写 [] |
| image | 是 | 英文画面描述：**景别 + 谁 + 在做什么 + 表情**。角色用中文名指代（如 林闲），管线会替换成角色 prompt |
| motion | action/insert 必填 | 英文，2 秒内能完成的一个动作 |
| line | talk 必填 | `[角色id, "中文台词"]` |
| emo | talk 建议 | 中文语气描述，如“懒洋洋地、拖着长音” |
| ref | 可选 | 特写镜头写 `"face"`，只用定妆照做参考，防止串图 |

### 写法规矩（都是踩过的坑）

- **前 3 秒必须有钩子**：冲突、反差或悬念，不要用风景开场超过 4 秒。
- **台词长度**：中文每秒约 4 个字。`dur` 秒的镜头，台词不超过 `dur × 4` 字。长台词拆成两个镜头。
- **台词里不要写方括号、括号、星号**。配音模型会把 “[叹气]” 念出来。语气全部写进 `emo`。
- **景别要换**：不要连续 3 个以上同景别。全景→中景→近景→特写交替。
- **一个镜头只做一件事**：AI 视频一次只能稳定完成一个动作。
- **特写加 ref: face**：大头/特写镜头只用脸部参考，否则会在画面里冒出同一个人的小全身像。
- **夜戏场景用 night_scenes 里的 id**，并在 image 里再写一次 night / moonlight / lamplight。
- **服装不在分镜里改颜色**：image 里不要重新描述衣服颜色，除非剧情需要换装（换装就新建一个角色 id，如 linxian_formal）。
- **时钟、文字、手机屏幕不要让 AI 画**：要么不拍，要么标注后期合成。
- **每集结尾留钩子**：最后 2–3 个镜头制造下一集的悬念。

## 第四步：检查和交付

1. 跑 `python3 scripts/check.py bible.json ep01.json [ep02.json ...]`。
2. 跑 `python3 scripts/check.py --table ep01.json > ep01_分镜表.md`，生成一张给人看的分镜表（镜头、时长、画面、台词），方便导演/用户审阅。
3. 交付时说明：总时长、镜头数、台词镜头占比、检查是否通过。

## 不要做的事

- 不用真实明星、影视/动漫角色、品牌 logo。全部原创。
- 不写血腥、色情和恐怖猎奇内容（平台审核过不了）。
- 不在 JSON 里写任何 API key 或个人信息。
